# RF-02 입력·생명주기 분리 검증

`GameController`가 키 설정을 명령으로 바꾸고 시작·중지·메뉴 종료를 관리한다. `Gamepanel` 생성만으로 게임을 시작하지 않으며, `Maincontainer`가 화면을 붙인 뒤 시작한다. 이 묶음에서는 기존 `Board` 규칙과 타이머를 유지한다.

## 확인 결과

- JDK 21에서 `./gradlew --no-daemon --console=plain clean check build` 성공.
- 전체 105개 테스트: 실패·오류·건너뜀 0개.
- JaCoCo Line Coverage: 1,565 / 1,731 = **90.41%**.
- 이후 Controller 생명주기·RF-01 경계 대상 검사 7개 통과.
- 별도 코드 리뷰: 수정 12개 파일, 차단 사항 없음. `git diff --check` 통과.
- 기존 production 32개 / test 3개 컴파일 경고 유지. 새 경고 없음.

생성 직후 미시작, 중복 start/stop, 종료 뒤 입력·재시작 차단을 추가로 검증했다. 기존 ESC 설정 우선순위와 pause 중 Enter 종료, 아이템 효과 취소 시나리오도 유지한다.

전체 실행 증거는 도구 세션 `65964`의 완료 출력(`bfd07d`, exit 0)에 기록됐다. 이후 대상 검사로 JUnit XML이 7개 결과로 교체되었으므로 해당 XML을 전체 105개 결과로 인용하지 않는다. 전체 실행의 정적 JaCoCo 보고서는 별도로 확인했다.

GUI/Robot 검사는 이 단계에서 실행하지 않았다. RF-01의 native MENU 실패는 사용자가 검사 중 컴퓨터를 조작했다는 후속 설명에 따라 **외부 입력 간섭 가능성**으로 기록한다. 원인이 확정되거나 문제가 해결된 것으로 간주하지 않는다.
