# RF-03/04 엔진 검증

화면·타이머와 독립된 `GameEngine`으로 Classic 규칙과 아이템 5종을 추출했다. 이 묶음의 실제 화면은 아직 기존 Board를 사용하며, 다음 묶음에서 연결한다.

| 경계 | 검증 내용 |
|---|---|
| 입력·고정 | 이동·회전·낙하 점수, 콤보·레벨·난이도, 생성 충돌 |
| 상태 사본 | 깊은 불변 값, 고정 셀·활성 블록 분리, ghost·미리보기 색상 |
| 고정 완료 | turnId 1회 소비, 삭제 직전 셀·원인·현재 블록 기원 복사 |
| 효과 | Row 5프레임 / Column·Cross 10프레임 뒤 확정, pause 중 진행 |
| 취소·공급 | 종료 시 효과 취소, 10줄 경계 누적 공급, 생성 실패 시 추가 공급 없음 |
| 아이템 | Anchor 접촉 잠금, Bomb 정착, Cross 원래 열 제거 후 행 압축 |

JDK 21의 전체 `./gradlew --no-daemon --console=plain check`에서 **133개 테스트 모두 통과**했다. 실패·오류·건너뜀은 0개이며 JaCoCo Line Coverage는 **1,952 / 2,125 = 91.86%**다. 엔진 전용 28개 테스트와 기존 UI 경로 검사를 함께 실행했다. 전체 로그는 작업 환경의 `/tmp/rf04-check.log`에 남겼다.

엔진 패키지에는 Swing·AWT·시스템 시계·파일·네트워크 호출이 없다. 경과시간과 블록 공급원을 호출자가 전달한다. 실제 대전·공격 정책·네트워크 전송은 이번 범위에 포함하지 않는다.

수동 고정은 이미 지난 중력 대기시간을 유지한다. pause/resume와 시간 기반 아이템 효과는 새 주기를 시작한다. 지연된 호출은 한 번에 최대 한 중력 이동 또는 한 효과 프레임만 처리한다.
