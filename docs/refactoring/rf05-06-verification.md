# RF-05/06 화면 연결·회귀 검증

Classic/Item 화면을 같은 `GameEngine`에 연결하고 Board의 규칙·타이머·아이템 대기 루프를 제거했다. 키 입력과 시간 진행은 Controller에서 직렬 처리하며, View는 불변 상태 사본만 그린다.

## 보강한 경계

- 두 엔진의 입력·블록 공급·pause·효과 취소·자연 종료 독립성.
- 입력 전 시간 정산 1회, 늦은 타이머 무시, 메뉴 종료 시 즉시 취소.
- pause 시 타이머 중단·resume 후 새 주기 시작, 자연 종료 시 이름 입력과 저장 흐름 1회.
- 생산 생성기의 블록당 난수 1회·매번 새 객체·기본 형상 독립성.
- 활성 아이템 문자 뒤 고스트가 남던 표시 문제: 수정 전 183개 픽셀 차이로 실패한 회귀 검사를 추가하고 수정 후 통과.

## native 검사에서 남은 사항

RF-01에서 실패했던 `Classic: MENU native press must arm the button`이 이번에도 재현됐다. 사용자가 입력을 비워두겠다고 답한 뒤 검사했으며, 이번 실패의 포커스 소유자는 `Gamepanel`이었다. 따라서 이전 실패를 사용자 조작 때문이라고 단정할 수 없다.

실패 지점은 MENU를 누른 채 밖으로 끌어 취소하는 경로의 **눌림 상태 확인**이다. 실제 클릭·게임 키·pause/resume는 이 지점까지 진행됐고, 같은 전체 경로의 합성 입력 검사는 통과했다. native 실패 원인은 확정하지 않았으며, 통과로 표시하거나 검사를 제거하지 않았다.

최종 로그·JUnit XML·JaCoCo XML·화면 캡처는 작업 공간 `.omx/evidence/rf06-20261031/`에 보관했다. 테스트 이관과 운영 코드에 대한 독립 리뷰를 진행했고, 발견된 검증 누락 두 건을 보완했다.
