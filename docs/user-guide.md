# SeoulTech SE Tetris 사용자 안내서

공식 제출 환경은 **macOS 26 이상 · Apple Silicon**이다.
공개 제출 버전은 **`v0.1.0-req2.3`**이다.

[릴리스 페이지](https://github.com/HoroyoiPeach/SeoulTech-SE-Tetris-Ref/releases/tag/v0.1.0-req2.3)에서 실행 파일을 받는다.
파일 무결성과 실행 검증 결과는 [검증 보고서](verification.md)에 정리했다.

## 1. 실행 파일 준비

배포 ZIP에는 Java 21 런타임과 아이콘이 포함된 macOS 앱이 들어 있다.

별도의 Java 설치 없이 실행할 수 있다.

| 실행용 ZIP | 압축 해제 후 실행 대상 |
|---|---|
| `seoultech-tetris-v0.1.0-req2.3-macos-aarch64.zip` | `SeoulTech Tetris.app` |

소스·문서·증빙까지 필요한 평가자는 같은 릴리스의 `seoultech-tetris-v0.1.0-req2.3-submission.zip`을 받는다.

실행 순서는 다음과 같다.

1. 위 표의 macOS 실행용 ZIP을 받는다.
2. ZIP 전체를 압축 해제한다.
3. `SeoulTech Tetris.app`을 더블클릭한다.
4. `TETRIS` 제목과 시작 메뉴가 표시되는지 확인한다.

## 2. 시작 메뉴

시작 메뉴는 위·아래 방향키로 이동하고 `Enter`로 선택한다.

| 메뉴 | 기능 |
|---|---|
| `CLASSIC` | 일반 블록으로 게임 시작 |
| `ITEM` | 줄 누계에 따라 아이템이 공급되는 게임 시작 |
| `MENU` | 설정 화면 열기 |
| `SCORE` | 전체·Classic·Item 기록 확인 |
| `EXIT` | 프로그램 종료 |

난이도와 화면 크기, 키, 색상 모드는 설정에서 선택한 값을 Classic과 Item 게임에 공통 적용한다.

## 3. 기본 조작

기본 키는 다음과 같다.

`MENU`의 `Change Keys`에서 여섯 동작을 모두 변경할 수 있다.

| 동작 | 기본 키 |
|---|---|
| 시계 방향 90도 회전 | `↑` |
| 한 칸 아래로 이동 | `↓` |
| 한 칸 왼쪽으로 이동 | `←` |
| 한 칸 오른쪽으로 이동 | `→` |
| 일시정지·재개 | `P` |
| 하드 드롭 | `Space` |

게임 중 `Esc` 또는 오른쪽의 `MENU` 버튼을 사용하면 현재 게임을 저장하지 않고 시작 메뉴로 돌아간다.

`Esc`를 게임 동작 키로 직접 지정한 경우에는 지정한 동작이 우선한다.

일시정지 화면에서는 다음 동작만 받는다.

- 현재 일시정지 키: 게임 재개
- `Enter`: 현재 게임 종료 후 시작 메뉴로 이동

아이템의 행·열 삭제 애니메이션이 진행되는 동안에는 이동 입력이 적용되지 않는다.

일반 완성 행에는 별도의 짧은 강조 표시가 적용된다.

## 4. 게임 진행과 점수

보드는 20행 × 10열이며 문자로 블록을 표시한다.

오른쪽에는 다음 블록과 현재 점수가 표시된다.

- 블록은 처음에 1초마다 한 칸 자동 낙하한다.
- 실제로 한 칸 내려갈 때마다 `1 × 현재 레벨` 점을 얻는다. 아래 키와 하드 드롭에도 같은 낙하 점수가 적용된다.
- 동시에 지운 행은 첫 번째 100점, 두 번째 200점처럼 행마다 100점씩 증가해 합산된다.
- 지운 행 누계가 10의 배수를 지날 때마다 레벨이 오르며 최대 레벨은 19다.
- 레벨이 높아질수록 낙하 간격이 줄어든다. Easy·Normal·Hard는 초기 1초는 같고 이후 증가 폭이 다르다.
- 다음 블록이 생성 위치에 놓일 수 없으면 게임이 끝난다.

게임 규칙과 정확한 산식은 [게임 명세서](specification.md)에서 확인한다.

## 5. Item 모드

Item 모드도 일반 블록과 같은 난이도·조작·점수 규칙을 사용한다.

지운 행 누계가 10줄 경계를 지날 때마다 아이템 공급 권리 1개가 생긴다.

아이템은 다음 블록 자리에 순서대로 나타난다.

여러 10줄 경계를 한 번에 지나면 공급 권리를 모두 보존한다.

다섯 아이템은 각각 20% 확률로 선택된다.

| 화면 표시 | 사용자에게 보이는 효과 요약 |
|---|---|
| `L` | `L`이 들어 있는 행을 지운다. `L`은 일반 테트로미노의 임의 점유 칸에 표시된다. |
| `O` | 밝은 회색 `#C0C0C0`의 폭 4 무게추 모양이다. 처음 닿은 뒤 좌우 이동이 잠기며, 아래 폭 4 영역을 비우고 바닥으로 내려간다. |
| `C` | `C`가 들어 있는 열을 지운 뒤, 모든 열의 남은 칸이 각 열 안에서 바닥까지 내려앉는다. 지운 열은 빈 상태로 남는다. |
| `B` | 3×4 폭탄 모양이다. 고정된 위치 주변의 직사각형 범위를 비운 뒤, 모든 열의 남은 칸을 바닥까지 내린다. 이때 완성된 행은 기존 줄 점수·누계·아이템 공급 규칙을 따른다. |
| `P` | 2×2 모양이다. 고정된 두 행과 두 열을 지우며, 두 행에는 100+200점과 2줄 누계가 적용된다. 열 삭제에는 별도 점수가 없다. |

[아이템 동작 영상](https://github.com/user-attachments/assets/802f2ea1-6f9c-48a9-a2f4-95a6dfa79e87)

아이템의 실제 모양, 회전, 발동 범위, 점수·줄 누계와 중첩 규칙은 [게임 명세서](specification.md)를 기준으로 한다.

B·C 정착에서는 각 열의 셀 순서·문자·색이 유지되며 열 사이로 좌우 이동하지 않는다.
P는 기존처럼 두 행을 삭제하며 위의 블록을 행 단위로 내린다.

## 6. 설정

시작 메뉴의 `MENU`를 열고 위·아래 방향키로 항목을 이동한 뒤 `Enter`를 누른다.

| 항목 | 선택 가능한 값·동작 |
|---|---|
| `Window Option` | `600X500` → `750X625` → `900X750` 순환 |
| `Change Keys` | Rotate, Down, Left, Right, Pause, Hard Drop 변경 |
| `Reset Scoreboard` | 저장된 모든 순위 기록 즉시 삭제 |
| `Color Option` | Normal, Protanopia, Deuteranopia, Tritanopia 순환 |
| `Difficulty` | Easy, Normal, Hard 순환 |
| `Reset setting` | 화면 크기·키·색상·난이도를 기본값으로 되돌림 |
| `Save and Exit` | 현재 설정을 파일에 저장하고 시작 메뉴로 이동 |

기본값은 `600X500`, 방향키/`P`/`Space`, `Normal` 색상 모드, `Easy` 난이도다.

화면 크기 표기는 `높이X너비` 순서다.

따라서 `600X500`은 내용 영역 높이 600, 너비 500을 뜻한다.

키 변경 화면에서 변경할 동작을 고르고 `Enter`를 누른 다음 새 키를 누른다.

- 여섯 동작은 서로 다른 키를 사용해야 한다.
- `Enter`는 일시정지 상태의 종료 동작에 예약되어 있어 Pause 키로 지정할 수 없다.
- `Change Keys` 안쪽의 `Save and Exit`는 변경값을 설정 화면에 반영한다.
- 바깥 설정 화면의 `Save and Exit`까지 선택해야 파일에 저장되고 새 창 크기·색상·난이도가 적용된다.

`Reset setting`은 순위 기록을 삭제하지 않는다.

순위 삭제는 `Reset Scoreboard`를 별도로 사용한다.

## 7. 게임오버와 순위

순위는 Classic과 Item 모드별로 상위 10개 진입 여부를 판단한다.

- 해당 모드에 기록이 10개 미만이면 이름 입력 화면이 나온다.
- 10개 이상이면 현재 점수가 기존 10위보다 높을 때만 이름을 입력한다. 10위와 같은 점수는 새 기록으로 들어가지 않는다.
- 이름은 영문 대·소문자와 숫자를 최대 10자까지 입력할 수 있다.
- 아무 글자도 입력하지 않고 `Enter`를 누르면 `PLAYER`로 저장된다.
- `Backspace`로 마지막 글자를 지운다.
- 저장 후 결과 순위표에서 방금 저장한 기록을 강조한다.

점수 화면의 `All`, `Classic`, `Item` 버튼을 누르거나 왼쪽·오른쪽 방향키로 필터를 바꾼다.

각 화면에는 상위 10개가 표시되며 이름·점수·난이도·모드를 함께 보여 준다.

`Enter`를 누르면 시작 메뉴로 돌아간다.

## 8. 설정·순위 파일

배포 앱은 사용자 홈 아래의 다음 디렉터리에 데이터를 저장한다.

```text
~/.seoultech-tetris/
  setting.txt
  tetris_score.txt
```

`~`는 macOS 사용자 홈 디렉터리를 뜻한다.

- 파일이 없으면 기본 설정과 빈 순위로 시작한다.
- 설정 파일에서 알 수 없는 항목이나 허용되지 않은 값은 적용하지 않고 해당 기본값을 유지한다.
- 점수 파일의 빈 행이나 지원하지 않는 형식은 순위에 넣지 않는다. 숫자가 아닌 점수가 있는 행도 건너뛴다.

문제가 생기면 앱을 완전히 종료한 뒤 위 디렉터리를 먼저 백업한다.

설정만 초기화하려면 `setting.txt`를 다른 이름으로 옮긴 뒤 다시 실행한다.

순위를 초기화하려면 게임의 `Reset Scoreboard`를 사용한다.

`tetris_score.txt`를 직접 삭제하거나 이동하면 기존 기록은 복구되지 않으므로 백업 후 처리한다.
